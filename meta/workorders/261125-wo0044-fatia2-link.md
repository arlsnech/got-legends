## 1. Por que

Fatia 2 da DEC-038. Hoje compartilhar uma build e copiar um bloco Base64 de ~1.480 caracteres, colar na gaveta de quem recebe e clicar em Carregar — e o texto exportado com o codigo chega perto do limite de 2.000 do Discord. Esta WO troca o codigo por um **link** que abre a build na ferramenta: o codigo vai no fragmento `#b=`, comprimido com o `CompressionStream` nativo (deflate-raw) e em base64url, com prefixo de versao `1.`.

## 2. Decisoes desta WO (escolhas tecnicas da raia de planejamento, dentro da DEC-038)

- **O link e montado quando a build ou o nome mudam** (um `useEffect` no `App`), nao no clique. A compressao e assincrona, e o Safari recusa gravar na area de transferencia depois de esperar uma promessa — risco listado na analise. Copiar e o Texto leem o link ja pronto.
- **«📋 Copiar» passa a «📋 Copiar link».** O campo da gaveta aceita o link inteiro, o codigo novo ou o codigo antigo (`decodeBuildLink` cai em `decodeBuild` sem o prefixo `1.`).
- **Abrir pelo link passa pela porta da WO C** (`requestOpen`): Desfazer, e «Salvar como…» se houver alteracao nao salva. Vale ao carregar a pagina e ao mudar o fragmento com a ferramenta aberta (`hashchange`). O `#b=` sai da barra com `history.replaceState` logo depois de lido.
- **Item, tecnica ou habilidade que nao existe mais** em `data.js` fica vazio (`dropUnknownIds`), e o aviso de rodape diz quantos. **Nao** confere propriedade e vantagem de item que existe — fica para quando aparecer o caso.
- **O texto exportado termina com o link** (`Link: …`), nao com o codigo; o interruptor das Configuracoes muda de texto, e a variavel `includeShareCode` fica com o nome que tem (renomear arrastaria o estado do `App` sem ganho).
- **`encodeBuild` e `decodeBuild` ficam em `logic.js`:** o primeiro nao tem mais uso no `App`, o segundo e o leitor do codigo antigo. Saem so do import do `App`.

## 3. Medido pelo chat, 2026-11-25 (Node 22, mesma `CompressionStream` do navegador, sobre o `logic.js` com a Ed. 1)

- 400 builds aleatorias: ida e volta **400/400** identicas, com o nome; codigo de **517 a 596** caracteres (media 563), sem `+`, `/` ou `=`; URL do GitHub Pages ~**604**.
- Codigo Base64 antigo: lido (`ok true`, com o nome). Lixo com e sem o prefixo `1.`: recusado (`bad_code`).
- Build com katana, tecnica I e habilidade inexistentes: `ok true`, `dropped 3`, os tres vazios.

// ─── LINK DE COMPARTILHAMENTO (Fatia 2, DEC-038) ──────────────
// O link leva só a build e o nome, comprimidos e em base64url, no fragmento
// `#b=` — que não vai ao servidor. O prefixo de versão decide como ler: formato
// novo é prefixo novo, NUNCA o mesmo prefixo com outro conteúdo, senão os links
// já espalhados passam a abrir errado em silêncio.
const LINK_CODE_V1 = '1.';

/** Bytes → base64url (sem `+`, `/` nem `=`, que a URL quebraria). */
function toBase64Url(bytes) {
  let s = '';
  bytes.forEach(b => { s += String.fromCharCode(b); });
  return btoa(s).replace(/\+/g, '-').replace(/\//g, '_').replace(/=+$/, '');
}

/** base64url → bytes. Lança se o texto não for base64 — quem chama trata. */
function fromBase64Url(text) {
  const b64 = text.replace(/-/g, '+').replace(/_/g, '/');
  const bin = atob(b64 + '='.repeat((4 - (b64.length % 4)) % 4));
  return Uint8Array.from(bin, c => c.charCodeAt(0));
}

/** Passa bytes por um CompressionStream/DecompressionStream nativo (sem dependência). */
async function pipeBytes(bytes, stream) {
  const out = new Blob([bytes]).stream().pipeThrough(stream);
  return new Uint8Array(await new Response(out).arrayBuffer());
}

/**
 * Codifica a build para o link: build e nome em JSON, deflate-raw nativo e
 * base64url, com prefixo de versão. Medido: ~530 caracteres, contra ~1.480 do
 * código Base64 antigo (análise 261116, M2).
 * @param {Object} build
 * @param {string} name
 * @returns {Promise<string>}
 */
export async function encodeBuildLink(build, name) {
  const json = JSON.stringify({ n: name || '', b: build });
  const packed = await pipeBytes(new TextEncoder().encode(json), new CompressionStream('deflate-raw'));
  return LINK_CODE_V1 + toBase64Url(packed);
}

/**
 * Tira o código de um texto colado: o link inteiro (`…#b=<código>`) ou só o código.
 * @param {string} text
 * @returns {string}
 */
export function extractShareCode(text) {
  const t = (text || '').trim();
  const i = t.indexOf('#b=');
  return i >= 0 ? t.slice(i + 3) : t;
}

/**
 * Esvazia o que a build cita e o data.js não tem mais — item de um slot,
 * técnica, habilidade — e conta quantos foram. Build de link pode ter sido
 * montada numa versão anterior da ferramenta; slot vazio com aviso é melhor que
 * slot fantasma. NÃO confere propriedade e vantagem de item que existe.
 * @param {Object} build  build já validada por deserializeBuild
 * @returns {{ build: Object, dropped: number }}
 */
export function dropUnknownIds(build) {
  const cls = getClass(build.classId);
  let dropped = 0;
  const gear = {};
  for (const [slot, st] of Object.entries(build.gear)) {
    if (st?.itemId && !getItem(st.itemId)) {
      dropped++;
      gear[slot] = slot === 'charm' ? { ...emptySlot(), linkedClass: build.classId } : emptySlot();
    } else {
      gear[slot] = st;
    }
  }
  const techs = { ...build.techs };
  for (const tier of Object.keys(techs)) {
    if (techs[tier] && !cls.techs.some(t => t.id === techs[tier])) { dropped++; techs[tier] = null; }
  }
  let abilityId = build.abilityId;
  if (abilityId && !cls.abilities.some(a => a.id === abilityId)) { dropped++; abilityId = null; }
  return dropped ? { build: { ...build, gear, techs, abilityId }, dropped } : { build, dropped: 0 };
}

/**
 * Lê um link ou código colado. Com o prefixo de versão, o formato novo; sem ele,
 * o código Base64 antigo (decodeBuild), que segue aceito na leitura (DEC-038).
 * Depois de validar, esvazia o que não existe mais (dropUnknownIds).
 * @param {string} text  link inteiro, código novo ou código antigo
 * @returns {Promise<{ ok: boolean, build?: Object, name?: string, dropped?: number, error?: string, code?: string }>}
 */
export async function decodeBuildLink(text) {
  const code = extractShareCode(text);
  let res;
  if (code.startsWith(LINK_CODE_V1)) {
    try {
      const bytes = await pipeBytes(fromBase64Url(code.slice(LINK_CODE_V1.length)), new DecompressionStream('deflate-raw'));
      const payload = JSON.parse(new TextDecoder().decode(bytes));
      const r = deserializeBuild({ game: 'got-legends', build: payload?.b });
      res = r.ok ? { ok: true, build: r.build, name: typeof payload.n === 'string' ? payload.n : '' } : r;
    } catch {
      return { ok: false, error: 'Código inválido ou corrompido.', code: 'bad_code' };
    }
  } else {
    res = decodeBuild(code);
  }
  if (!res.ok) return res;
  const { build, dropped } = dropUnknownIds(res.build);
  return { ...res, build, dropped };
}

   * Abre a build de um link ou código — o colado na gaveta ou o da barra de
   * endereço — pela mesma porta do clique num salvo (requestOpen, WO C).
   * @param {string} text
   * @returns {Promise<boolean>} se abriu, ou se foi para a pergunta de alteração não salva

    if (!r.ok) {
      showToast(tl('✗ Link ou código inválido', '✗ Invalid link or code'))
      return false

    const note = !r.dropped ? ''
      : r.dropped === 1

  // é assíncrona, e o Safari recusa gravar na área de transferência depois de
  // esperar uma promessa (análise 261116, Riscos).
  useEffect(() => {
    let alive = true
    encodeBuildLink(build, buildName)
      .then(code => { if (alive) setShareLink(`${window.location.origin}${window.location.pathname}#b=${code}`) })
      .catch(() => { if (alive) setShareLink('') })
    return () => { alive = false }
  }, [build, buildName])

  // Abrir pelo link: ao carregar a página e quando o fragmento muda com a
  // ferramenta aberta. O #b= sai da barra logo depois de lido — senão recarregar
  // a página reimportaria por cima do que a pessoa editou (análise 261116, Riscos).
  useEffect(() => {
    const read = () => {
      const h = window.location.hash
      if (!h.startsWith('#b=')) return
      history.replaceState(null, '', window.location.pathname + window.location.search)
      openFromLinkRef.current?.(h)
    }
    read()
    window.addEventListener('hashchange', read)
    return () => window.removeEventListener('hashchange', read)
  }, [])

  // Arrasto de arquivo para qualquer ponto da tela (B1–B6). Sem isto o navegador
